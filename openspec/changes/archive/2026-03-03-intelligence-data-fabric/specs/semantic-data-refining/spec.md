## ADDED Requirements

### Requirement: Sampling-Based Semantic Mapping
The system SHALL provide a `SemanticCleaner` node that takes a small sample (top 100 rows) of a dataset and uses an LLM to identify semantic inconsistencies (e.g., date formats, company name variations).

#### Scenario: Rule generation from sample
- **WHEN** a dataset contains three different variations of "Alibaba Group" (e.g., "Alibaba", "ALIBABA", "Alibaba.com")
- **THEN** the `SemanticCleaner` SHALL generate a deterministic mapping rule (JSON or Regex) that unifies these values.

### Requirement: High-Speed Rule Application
Once a mapping rule is generated by the AI, the system SHALL apply it to the entire dataset using a native Rust transformation node (e.g., `ProjectNode` or `MapNode`) without further LLM calls.

#### Scenario: High-speed application to millions of rows
- **WHEN** a mapping rule is applied to a 1,000,000 row RecordBatch
- **THEN** the transformation SHALL occur at native CPU speed using DataFusion's expression engine.
